# 일등대리 — 앱에 표시되는 혜택·금액 문구 정리

> **목적**: 마케팅·CS·백엔드 정책을 맞출 때 참고용. 아래는 **소스 코드/화면에 적힌 문구**만 옮긴 것이며, 실제 지급·적립 조건은 **서버·약관·운영 정책**을 기준으로 확인해야 합니다.  
> **기준 시점**: 저장소 내 Dart UI 문자열 기준.

---

## 1. 마일리지 (적립·비율)

| 화면·위치 | 앱에 적힌 내용 |
|-----------|----------------|
| 홈 — 상단 배지 옆 | `카드 결제 10% 적립` |
| 마일리지 — 잔액 카드 하단 | `가입 시 10,000원 / 카드 결제 10% 적립` |
| 카드 관리 | `카드거래시, 요금의 10% 마일리지적립.` |
| FAQ — 마일리지 | `가입 시 10,000원 지급, 카드 결제 시 이용금액의 10% 적립됩니다.` |
| FAQ — 전화 접수 | `전화 접수 시 10% 적립됩니다.` (1668-0001) |
| 추천인 현황 — 기본 혜택 | `앱 가입 완료 시 10,000원 적립 (추천 아님)` + 줄바꿈 + `카드 결제 시 이용금액의 10% 적립` |

## 2. 신규·첫 고객·가입 혜택

| 화면·위치 | 앱에 적힌 내용 |
|-----------|----------------|
| 홈 — 공지/배너 폴백 제목 | `신규 가입 시 1만원, 친구 추천 이벤트 진행 중!` |
| 내추천인 등록 — 큰 숫자 | `추천받고` / `10,000원` / `받기` |
| 내추천인 등록 — 양방향 카드 | 추천받은 사람: `10,000원`, 부가 `가입 시` / 나를 추천해 준 분: `2,000원`, 부가 `친구 등록 시` |
| 내추천인 등록 — 버튼 | `등록하고 10,000원 받기` |
| 내추천인 등록 — 성공 스낵바 | `추천인 등록 완료 (10,000원)` |
| 추천인 현황 — 추천인 혜택 블록 | `친구 가입 시 2,000원 → 첫 이용 시 3,000원 추가 → 친구 이용할 때마다 이용금액의 2% 적립!` |
| 추천인 현황 — 빈 상태 안내 | `친구 추천하면 2천원! 첫 이용 시 3천원! 이용할 때마다 2%` |

## 4. 친구 추천 — 실물 쿠폰(쿠폰함 UI)

| 화면·위치 | 앱에 적힌 내용 |
|-----------|----------------|
| 쿠폰함 — 안내 제목·부제 | `친구 추천 상품 쿠폰` / `마일리지와 별도로 지급되는 실물 쿠폰이에요` |
| 쿠폰함 — 단계별 보상 | `2명 추천` → `스타벅스 음료 쿠폰 2장` / `5명 추천` → `교촌치킨 세트 쿠폰` |
| 추천인 현황 — 실적 배지 | `2명 추천` → 보상 표기 `스타벅스` / `5명 추천` → `교촌치킨` |
| 추천인 현황 — 다음 보상 카드 | 2명 미만: `스타벅스 쿠폰 2장` / 2~4명: `교촌치킨 세트` / 5명 이상: `모든 보상 달성!` |
| 쿠폰함 — 빈 목록 | `친구를 추천하면 상품 쿠폰이 지급돼요!` |
| 쿠폰함 — 푸터 안내 | `쿠폰은 마일리지와 별도로 지급되며, 유효기간은 발급일로부터 30일입니다.` |

## 5. 마일리지 출금 (금액·수수료)

| 화면·위치 | 앱에 적힌 내용 |
|-----------|----------------|
| 출금 화면 — 검증 메시지 | 최소 `20,000원`, 단위 `10,000원` |
| 출금 화면 — 수수료 표기 | `500원` |
| 출금 화면 — 안내 문단 | `출금액은 20,000원 이상 10,000원 단위로 가능하며, 출금 시 500원 수수료가 부과됩니다. 영업일 기준 1~2일 내 처리됩니다.` |
| FAQ — 출금 | `잔액 전액 출금 가능합니다. 20,000원 이상 10,000원 단위로 출금 신청하세요.` |

> **참고**: FAQ는 “잔액 전액 출금 가능”으로 적혀 있고, 출금 입력 화면은 “2만 원 이상·1만 원 단위”를 강조합니다. 대외 문구·실제 로직을 한번에 맞추는 것이 좋습니다.
